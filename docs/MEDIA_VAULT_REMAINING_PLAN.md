# Media Vault 原始计划与完整后续步骤

第 22 步为 Oracle VPS 出站代理部署与启动。账号配对是无需复制长期密钥使用
下载功能的前置工作，没有替代原来的下载项目。原始顺序和范围不变。

## 原始目标与约束

接入现有 Media Vault 的小说 EPUB、中文漫画 CBZ、视频及 Aria2/BT。
HTTPS Worker / D1 仅保存队列、元数据及账本，VPS 主动出站，不需自有域名，
不新增公网应用端口。最终文件由浏览器保存到本机，不归档至 Cloudflare、GitHub
或 Actions Artifacts。默认关闭账号访问、提交及两端流式，不修改已发布生产页面。
临时空间 12 GiB、正常保留 24 小时、自设传输预算 100 GiB/月保持不变。
活动传输、身份不符或元数据不可用时遵守保留保护；ACK 不表示本机落盘完成。
