- 前端和服务端任务契约、取消检查点、累计内容边界、纯文字/排版、目录/章节选择、重建。
- 两个候选分支纳入主线，保留既有小说缓存恢复和手动补入正文。
- 最新加入 MangaDex 中文托管章节，真实来源链路和实际归档检查通过。
- Windows runner 原生落盘、实际浏览器进程重启、离线验收和篡改拒绝通过。
- 完整相关回归及配套关闭部署通过。生产未发布、两 PR 仍草稿。

## 必须保留的失败与限制

- 固定小说真实页面入口出现 ERR_BLOCKED_BY_CLIENT / 浏览器策略拒绝；没有绕过，
  未完成目录/三排版/取消/重建的真实页面操作。
- Windows 首次及诊断检查发现图片夹具不能由 Chromium 解码；有效 PNG 夹具修正后
  重跑通过。没有弱化离线图片校验，也没有把先前失败覆盖为成功。
- 云端 Windows 的真实磁盘结果不是用户本人设备观察；短时真实进程重启不是长期经过。
- 此前临时窗口已关闭，旧文件票据额度已消费；不能重置或复活过期授权。
- Commons 样例和 MangaDex 中文托管章节不代表所有中文漫画站兼容。

仍保留本人 Windows、真实长期观察、受阻小说页面三项条件，以及独立合并发布决定。
