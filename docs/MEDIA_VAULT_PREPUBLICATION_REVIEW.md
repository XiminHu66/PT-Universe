## 四项仍需真实验收

1. **固定小说页面操作**：当前远程浏览器访问专用入口受策略限制。不能换请求通道绕过。
   能力恢复后再确认一个设备、一本固定书前两章、纯文字、三种排版、取消/重建、
   最多四项账号任务、30 分钟、零票据的范围；完成后退出/撤销、关闭并核对账本。
2. **Windows 本机保存**：须使用用户自己的 Windows 浏览器及下载目录观察结果。
   重新确认文件、字节与票据上限、期限和关闭动作；不重置已消费的三票额度。
   检查浏览器显示完成、文件实际存在、大小和 SHA-256；EPUB/CBZ 打开结构和中文内容，
   MP4 检查容器。`Get-FileHash -Algorithm SHA256 -LiteralPath <已保存文件>` 可生成本机哈希。
   无需在页面或聊天粘贴 Owner/Agent 密钥、Cookie 或账户密码。
3. **长期设备保持**：记录真实开始/结束时间、同一设备重开浏览器后的任务恢复与登出状态；
   校验绝对期限与撤销后不可恢复。模拟时间只验证逻辑，不计入真实持续观察。
4. **更广中文漫画来源**：当前适配器明确为 Commons 许可样例。需要确定具体来源、选择
   可访问作品和真实章节，完成来源适配、限流/错误处理及 CBZ 页序、中文元数据和内容校验。
   通用漫画站支持尚未交付，不能写成发布功能已完成。
