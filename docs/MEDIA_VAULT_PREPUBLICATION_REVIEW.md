### 原计划剩余条件与最终确认

1. 固定小说真实页面操作：专用入口受当前浏览器策略阻断，未换通道绕过。
2. 用户本人 Windows 设备落盘：平台兼容性通过，本人设备尚未观察。已有文件可用
   `scripts/media-vault/verify-local.html` 离线验收；没有文件则需另行具体有界下载范围，
   不能重置已花完的旧窗口。详见 `MEDIA_VAULT_DEVICE_ACCEPTANCE.md`。
3. 真实较长时间设备观察：进程重启通过，真实经过的长期恢复/到期/撤销未观察。
4. 独立合并/生产发布决定：两 PR 继续草稿，不合并、不发布、不启用新权限。

机器清单仅移除已完成的中文来源缺口。关闭候选检查通过，`--release` 继续拒绝发布。
没有默认缩小原始目标，没有用云端测试充当用户本人设备或真实经过长期的证据。
