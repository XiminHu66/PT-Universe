## 已保存文件的离线校验

下载 `scripts/media-vault/verify-local.html` 到 Windows，使用 Chrome 或 Edge 双击打开。
选择本轮已经保存的 EPUB、CBZ、MP4，点击“开始校验”；通过后点击保存 JSON 报告。
文件名可以不同，清单以已有三份样例的准确大小和 SHA-256 匹配。此页不连接网络、
不自动读取其他文件、不上传媒体或 Cookie，也不要求输入安全密钥。报告不含完整目录路径。
CBZ 检查页序/图片/XML，EPUB 检查结构/XML/图片，MP4 检查容器头；MP4 可播放体验
仍需在本机播放器观察。三份已有远程 Chrome 证据并不表示用户 Windows 已保存同样文件。
若本机没有这些文件，不要为了验收复制或重置旧票据预算；需先准备并确认新的有界
下载授权，且旧的 `account-files-on` 会因先前已消费票据而拒绝重开。不要移除该保护。
