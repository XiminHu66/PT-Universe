## 当前合并与自动发布关系

公共 PR 合并到 `main` 会触发 `.github/workflows/pages.yml`，发布整个 GitHub Pages 网站。
该流程还会读取当时最新的 `main`，因此最终批准时必须再次核对目标提交；不能把公共合并
说成不会发布。本次 PR 包含 Media Vault `app.js` 和 `index.html` 的既有候选改动。

当前公共 PR 不修改 `workers/pt-universe-api/**` 或其生产部署工作流，因此不会因当前
文件差异触发生产 API 的 push 部署；如最终差异变化，须重新核对。专用 Hybrid Worker
与 VPS 部署工作流均为手动操作，公共合并不会自动启用账号、任务提交或两端流式。

配套 PR 合并不等于 VPS 运行时更新。不得因分支合并而复制密钥、迁移媒体或开放端口。
合并时保留主线的无关更新；已审查的主线后续变化仅为行情数据，与候选没有文件重叠。

## 一次完成剩余人工验收的操作单

### 固定小说真实页面

目前远程浏览器入口受到浏览器策略阻断；不换 URL、浏览器或 CI 路径绕过。
用户可在自己的原 Windows 浏览器独立进行此项验收。开始前需明确批准以下新窗口，
由服务端使用现有 Secrets 开启并批准用户新提供的公开会话 ID：

- 固定 `https://www.wenku8.net/book/3551.htm` 前两章、纯文字；一个设备、30 分钟。
- 全账号最多四项任务，三种既定排版，零文件票据；Worker/VPS 文件流始终关闭。
- 在真实页面读取目录、选择章节、查看三种排版预览，实际创建紧凑/标准/大字任务。
  紧凑任务先取消，再从取消状态重建；重建保留原参数，计入四任务上限。
- 若任务已完成而来不及取消，不增加第五项任务或静默重开窗口；记录该步骤未完成。
- 刷新和重开浏览器后检查任务恢复；记录实际结果，不发送 Cookie、密钥或配对凭据。
- 完成后退出/撤销，关闭窗口，核对零新增传输字节及零预留。

此窗口尚未开启，不复用三文件下载窗口的授权或旧会话。完成页面任务不能计为实际
EPUB 下载；本窗口明确不签发票据。

### 实际长期会话观察

已有真实浏览器进程重启和短时恢复通过；自然经过较长时间、绝对到期与撤销后的拒绝
仍未完成。已撤销会话之后经过的时间，不构成有效会话持续观察。七天 Cookie 是上限，
不是七天实测证明，也不自动定义此次观察时长。

开始前明确观察的最短实际时长及只读权限范围，并记录批准。已有只读验收入口上限为
20 分钟，小说入口上限为30分钟；不能重复开窗或修改系统时间冒充更长的会话。
若需要更久的观察，先准备对应的有界只读模式，再另行批准启用。任何新模式仍必须
禁止任务提交和票据，不得启用常规五任务/一百票据权限来替代只读观察。

记录真实起止时间、同设备恢复、浏览器重启、自然到期、退出/撤销后的拒绝，以及用户
确认。机器证据需要 `approved_minimum_ms` 和实际时长；它不替代真人确认或自动证明
观察记录真实。此项不能在一次短会话中凭自动化结果直接完成。

## 机器检查与合并顺序

1. 公共 CI 检查默认关闭、生产候选源指纹、打包资产一致性和验收证据。
2. 配套 CI 固定公共40位提交，执行跨组件、Windows 原生保存与 Agent 校验；不部署。
3. `node workers/media-vault-hybrid/candidate-check.mjs` 应通过；它允许明确保留未完成条件。
4. `node workers/media-vault-hybrid/candidate-check.mjs --release` 只有真实验收证据、明确
   观察时长/结果、用户批准及对自动部署的知情确认齐全后才能通过。仅清空 `pending`
   不会解除限制；CI 夹具、时钟模拟和普通“继续开发”也不能充当发布批准。
5. 条件齐全后提交两份 PR 的确切版本和最终差异，获得包含 Pages 自动发布的独立决定。
   再按配套 PR、公共 PR 顺序合并，观察实际触发的 Pages 部署。此前不标记 ready、不合并。

## 回退与关闭

合并前出错：保留草稿和关闭配置，修复后只重跑受影响检查。
合并后页面出错：在新的审查提交中 revert 公共合并并观察 Pages 重新部署，不清空 D1、
账户历史或票据账本。专用 Worker/VPS 的权限继续关闭；必要的运行时回退使用已审查的
关闭版本，不因回退扩大任何权限。配套源码回退不自动执行 VPS 部署。

当前结论：可自动执行的实现和候选验证集中完成；真实小说页面、实际长期观察和独立
合并发布决定继续保留。若用户希望调整验收范围，需明确记录调整，不能默认为全部通过。
