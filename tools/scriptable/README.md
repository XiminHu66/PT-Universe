# PT Widgets for Scriptable

一个脚本，添加三张卡。每张卡在 Scriptable 小组件的「Parameter／参数」选择自己的模式。

| 卡片 | 参数 | 建议位置 | 内容 |
|---|---|---|---|
| 投资行动卡 | `invest` | 主屏幕中号，小号可选 | 优先显示已经达到、其次最接近你手动参考价的标的。中号最多 3 只，小号 1 只。 |
| 免费游戏与大额 Deal | `deals` | 主屏幕中号 | 优先放一条免费游戏和一条优惠。各行可以点到原活动；没有命中时显示状态。 |
| 机核新闻 | `news` | 横屏待机小号 | 一条机核文章标题，使用大字排版。整张卡点开文章。主屏幕中号可显示两条。 |

另见 [原生待办设置教程](REMINDERS.md)。

## 安装

1. 在 iPhone 的 Safari 打开 [PT-Widgets.js](PT-Widgets.js)，打开 **Raw** 并复制全文。
2. 已安装旧版时，编辑原有的 **PT Widgets**，用新入口代码替换全文并保存。这次迁移只做一次。首次安装则点 **＋**，把脚本命名为 **PT Widgets** 后粘贴并保存。联网运行一次，第一次会下载发布版，完成后可以预览卡片。
3. 回到主屏幕，长按空白处 → **编辑 → 添加小组件 → Scriptable → 中号**。添加后长按卡 → **编辑小组件**，将 **Script** 设为 `PT Widgets`，将 **Parameter** 设为 `invest`。重复一次，第二张填 `deals`。
4. 横屏配置请看下文。已有组件会继续使用同名脚本和原参数，可直接跳过步骤 3。

## 以后怎么更新

打开 Scriptable，运行 **PT Widgets → 检查更新**。看到「已安装」后，下次打开脚本或 iOS 刷新时就会使用新版。菜单标题会显示运行版本。三张卡共用一套代码，手机里已导入的自选股、参考价、优惠规则和通知记录可以继续使用。

代码更新只会在首次联网运行和点「检查更新」时发生。普通组件刷新从手机读取已安装版本。更新失败时保留旧版；若新版代码无法加载，或组件渲染抛错，组件会依次尝试已安装的旧版。这里更新的是组件代码，Daily Nexus 的新参考价仍通过原来的导入流程传到手机。

## 连接 Daily Nexus

1. 在平时修改参考价的浏览器打开 [Daily Nexus 看板](https://ximinhu66.github.io/PT-Universe/apps/daily-nexus/?view=board)。点击股票区右上角 **手机同步 → 启用同步 → 复制配对码**。
2. 在 iPhone 的 Scriptable 运行 **PT Widgets → 连接 Daily Nexus**，粘贴配对码并点连接。网页在电脑上时，用 AirDrop、通用剪贴板或你自己的设备间传输方式，将配对码交给 iPhone。首次连接成功后不再需要复制。
3. 在网页原来的看板保存增删标的或参考价。通常一秒左右开始上传。投资卡会在 iOS 调度刷新时拉取，10 分钟内可复用上次读取的清单。想立即核对，运行 **预览投资行动卡**，会主动拉取一次，断网时组件会显示上次同步清单。
4. 同步只包含股票代码、标签和手动买卖参考价。网页加密后使用独立的同步资料，Scriptable 配对码放在钥匙串。其他浏览器若已有自己的看板配置，手机以你配对的网页清单为准。同步支持美股、美股 ETF 和列明的常见指数及 Coinbase BTC／ETH 美元标的，最多 20 只，优先保留设价的项。
5. JSON 备份仍可用。需要离线导入时，在网页 **设置 → 显示与备份 → 导出配置 JSON**；在 Scriptable 选 **导入 Daily Nexus 自选股**。连接时网页清单优先，断开可保留最后同步的清单。

行情使用 Yahoo Finance 的常规盘价格和源时间戳，可能延迟。达到买价按现价 ≤ 手动买价，达到卖价按现价 ≥ 手动卖价。盘中行情超过 25 分钟或请求失败时，历史价格标记为「旧行情」，停止用它判断触线。休市时显示上次常规盘价格和日期。距离按 `|现价 ÷ 参考价 − 1|` 计算。参考价及关注规则保存在手机本地。行情请求会将用于报价的标的代码发送给 Yahoo。

## 免费游戏和优惠

- Epic 读取已有优惠雷达的国区官方活动，只显示有明确截止时间的「免费领本体」。Steam 使用已有 Deal Lab 所采用的 GamerPower 数据源的公开接口，只读完整游戏活动，并排除可识别的试玩或积分门槛。领前在活动原文确认资格、库存和截止时间。
- 美国优惠使用已有优惠雷达的 Slickdeals 数据。默认筛选标题明确写明省至少 **$100**，或 **至少 50% off 且标题报价 ≥ $80** 的帖子。帖子价格和折扣以活动原文为准。
- 设置具体商品时，运行 **PT Widgets → 设置 Deal 关注价 → 新增或更新一条**，例如关键词 `Mini PC`、最高价 `500`。也支持从剪贴板批量导入，每行一个，格式 `Mini PC | 500`。同一关键词可以重新输入覆盖，最多 15 条。匹配的是明确标题报价，可识别的起价、以旧换新和模糊价格会跳过；已知券条件会标记。
- 如要试通知，先在 Scriptable 内点 **检查本次优惠通知**，并允许 iOS 通知。可选的定时检查由 iPhone「快捷指令」触发。在「快捷指令」新建一个快捷指令，添加 Scriptable 的 **Run Script／运行脚本**，选 **PT Widgets**，展开动作将输入 **Parameter** 设为文本 `alerts`。手动试跑后，在「自动化」创建「特定时间」日程，选择该快捷指令，开启「立即运行」或关闭「运行前询问」，视 iOS 版本而定。可从每天 09:00、18:00 两次开始，各建一个触发。脚本按活动 ID 去重，只用合格的近期数据通知。未创建自动化时，卡片仍可显示；刷卡本身不会发通知。

## 新闻放进横屏待机

1. 打开「设置 → 待机显示」。锁定 iPhone，再横放在磁吸充电器上，保持静止。左右滑到两个小组件并排的页面。
2. 长按右侧组件堆叠，按要求解锁，点 **＋** 找 **Scriptable**。添加小号后，从编辑视图选中该组件，将脚本设为 **PT Widgets**，参数填 `news`。如果你当前的 iOS 界面允许退出编辑后再长按「编辑小组件」，也可从那里设置。
3. 关掉该堆叠的「智能轮替」和「小组件建议」，可以固定显示新闻。也可以保留「提醒事项」在同一堆叠，竖向滑动切换。
4. 若 StandBy 组件库里没有 Scriptable，先打开 Scriptable 跑一次「预览横屏版新闻」，再回到 StandBy 搜索。若仍未出现，就用同一脚本的主屏幕小号。主屏幕可用的小组件是否进入 StandBy 组件库也取决于 App 本身。
5. 这张卡只读取 RSS Orbit 的机核缓存源，并筛选文章链接。远距离主要看一条标题，主屏幕中号使用日间主题，小号在深色系统外观下使用高对比深色。横屏夜间模式可能由 iOS 着色。实际显示和点按后是否需要解锁，以你的 iPhone 为准。

Apple 让 iOS 决定小组件何时刷新。脚本按模式建议刷新间隔，并从现有公开读取接口取数；它不触发现有服务器的手动刷新任务。

[Scriptable 组件文档](https://docs.scriptable.app/listwidget/) · [Apple StandBy 说明](https://support.apple.com/guide/iphone/use-standby-iph878d77632/ios) · [Apple 快捷指令自动化](https://support.apple.com/guide/shortcuts/add-automations-apdfbdbd7123/ios)

## 仓库发布方式

- `PT-Widgets.js` 是一次安装的入口。维持入口 API 兼容，让后续发布只更新 `PT-Widgets.runtime.js`。
- 发布新版时，将运行文件首行与 `VERSION` 的数字一起递增。在验证后，把 `scriptable-widgets-stable` 分支的 `tools/scriptable/channel.json` 指向该运行文件所在的完整提交 SHA。格式为 `{"api":1,"version":1,"commit":"<40 位提交 SHA>"}`。每个版本号只对应一个发布提交。
- 更新器从该分支读发布信息，再按指定提交下载运行文件。部署可以直接使用 GitHub 文件读写，不需要添加 Actions 工作流。
