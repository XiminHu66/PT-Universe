# iPhone 待办清单和横屏待机教程

推荐用 iPhone 自带的「提醒事项」。先把「今天」放到主屏幕和横屏待机，再根据使用习惯加一个「明天」列表。

## 1. 准备列表

1. 打开「设置 → 你的姓名 → iCloud → 查看全部」，开启「提醒事项」，用同一 Apple 账户在设备间同步。只在这部手机使用时，可以使用当前已有的提醒事项账户。
2. 打开「提醒事项」。返回「我的列表」总览，点「添加列表」，创建常用的标准列表，例如「个人」。「今天」是系统智能列表，自动汇总有今天日期的未完成事项及逾期事项。如果总览里看不到「今天」，点「更多 → 编辑列表」，启用它。
3. 在「个人」里添加一条测试待办，例如「检查待机组件」。点新提醒旁的日期按钮或详情「ⓘ」，设置今天的日期。有截止时间的事项再选时间。长期随手记可以留在「个人」，有确定要做的日期再加日期。
4. 如果经常晚上预览第二天，打开系统自带的「计划」，按日期找到明天。想在待机中单独固定一份晚间清单，可以另外建一个标准列表「明天要做」，然后在组件里选它。这个标准列表由你手动维护。

## 2. 放到主屏幕

1. 长按主屏幕空白处，看到图标抖动后点「编辑 → 添加小组件」。旧版 iOS 可能直接显示左上角「＋」。
2. 搜索「提醒事项」，选**中号**看多条待办，或选小号节省空间。点「添加小组件 → 完成」。
3. 长按新卡片 →「编辑小组件」→ 点「列表」→ 选「今天」。
4. 点测试事项前的圆圈。它应从卡片和未完成列表里消失。需要撤回时，打开原列表的「更多 → 显示已完成」，取消勾选。

## 3. 放到磁吸充电器的横屏待机

1. 打开「设置 → 待机显示」，开启功能。把 iPhone 锁屏，横放在已经通电的磁吸充电器上并保持静止。
2. 左右滑到双组件页。左边保留时钟，长按右边进入编辑，按提示解锁。
3. 点「＋」→ 搜索「提醒事项」→ 添加小组件。如果组件有默认列表，点它或从退出编辑后的组件菜单进入列表配置，选「今天」。点「完成」。部分系统显示「提醒事项」后直接给列表可选。
4. 在右侧上下滑动切到待办。想固定这一页，就在堆叠编辑里关闭「智能轮替」及「小组件建议」。想看新闻时，可以把 Scriptable 小号的 `news` 卡加到同侧，用上下滑动切换。
5. 有常亮显示的机型，可在「设置 → 待机显示 → 显示」查看设备支持的熄屏选项。其他机型熄屏后可轻触屏幕或轻碰支架唤起。若待办可能被旁人看到，给待机专门选一个标题适合公开展示的标准列表。

## 4. 用一天的检查方法

- **「今天」是空的**。在提醒事项 App 打开「今天」，确认任务未完成且日期为今天。无日期的事项会留在原列表。
- **另一台设备新增的任务没出现**。核对两个设备使用同一 Apple 账户、各自开启了 iCloud「提醒事项」，并确认该事项加入的是 iCloud 下的列表。
- **能看到待办，但点完没立即变化**。点圆圈并按系统要求解锁，再打开「提醒事项」确认完成状态。检查小组件选中的是否同一个列表。
- **横屏只有大时钟**。左右滑到双组件页。一直进不了待机显示时，检查是否正在充电、是否锁屏、能否稳定横放，以及「设置 → 待机显示」是否已打开。
