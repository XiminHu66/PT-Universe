# AnythingLLM · PT Chat

An independent PT Universe chat tool inspired by AnythingLLM's workspace and provider selection UX. It is not the upstream AnythingLLM server and does not claim its vector RAG, agents, or full document ingestion features.

- Static frontend: `apps/anythingllm/`; linked from the PT Universe homepage and Daily Nexus toolbox.
- Streaming API: existing PT Universe Worker, `/api/anythingllm/{chat,models,status,quota}`.
- `providers.json` contains only recurring free API providers. Trial, promotional, application-only and discontinued offers are recorded in the excluded research notes, never displayed as selectable chat backends. Aggregators have their own filter. OpenRouter and pinned free-model providers are enforced server-side even if a caller supplies allowPaid=true.
- User API keys stay in tab sessionStorage. The Worker forwards them only to fixed official HTTPS endpoints; it does not persist keys or conversation content. Custom endpoints and localhost run directly from the browser and need CORS. Runtime platform observability settings still apply.
- Existing backend Gemini supports an owner-only connection through the existing private PT tools hub. The user clicks Connect PT backend, signs in with the native existing account, and returns automatically. The hub signs a 1-hour ES256 capability; its private key remains a Sites runtime secret. PT Worker pins the public key and checks issuer, audience, scope, owner, expiry and signature. A per-tab nonce is checked on return, the URL fragment is immediately removed, and the capability stays in sessionStorage, excluded from backups. Already-enrolled sync accounts remain compatible. Shared usage keeps atomic 6/minute, 150/day and 60/day per-owner limits. No Gemini API key is sent to the frontend.
- Chat/workspace data stays in browser localStorage, outside the existing `ptu.*` sync scope. JSON backups and Markdown exports exclude keys. Import replaces current chats only after confirmation.
- Text attachments only (up to 5, combined 55,000 characters); one message limited to 60,000 characters; requests to 120,000. Latest 40 completed messages plus workspace system prompt are sent to the selected backend. Switching provider sends that conversation context to the newly selected service. No automatic cross-provider fallback.
- OpenRouter's default free mode only permits `openrouter/free` or `:free`. Other providers require the appropriate free account plan; the UI cannot guarantee zero billing on a paid account. Account billing remains controlled by the upstream provider; use its Free plan.

Checks: `node scripts/anythingllm/core-test.mjs` and, inside the Worker directory, `node tests/anythingllm.test.mjs`, `npm run check`, `npx wrangler deploy --dry-run`. The connection test makes one small real completion when clicked. Model listing does not verify generation or free entitlement.

The chat remains hosted on PT Universe GitHub Pages. The existing private tools hub is only the sign-in bridge, not a second chat site. Its service-access bearer does not supply user identity and cannot mint owner capabilities.

Model discovery: the model controls are complete selects, rather than datalists filtered by the current input. Opening the page, selecting a provider, saving a Key, returning to the tab, and every 10 minutes refresh configured providers. Gemini uses a public read-only ID catalog (no chat access): parses the official English Standard free-tier input and output price columns, intersects the paginated native Models API and generateContent capability, and separates dedicated audio/image/embedding interfaces. No generation probes or token consumption during discovery. Per-key results are SHA-256 keyed in bounded memory for 10 minutes; public pricing for one hour. On discovery failure a clearly marked last-verified catalog is retained. OpenRouter intersects :free IDs with zero prompt/completion prices. Other providers use their account model endpoint and existing free-model/Free-plan restrictions. The current model is preserved if it remains in the list.
