导入 / 导出

完整备份与 Obsidian Markdown

完整数据

导入原项目的 worklog.json，保留层级、记录、待办和日志。导入前会保存当前版本。

Obsidian 导出

项目树、项目记录、开放待办、归档与每日笔记会导出为 Markdown；日期是新增与完成时间，不作为截止日期。

自动备份

保留最近 30 份快照。每天首次修改前和导入、接收云端数据前保存一份；仅保存在此浏览器。

操作说明

项目只组织工作；待办保持开放，直到你勾选完成。日期记录新增和完成时间，不会让待办过期。项目记录与每条待办日志独立编辑。

所有结构操作也可用项目面板中的按钮与“移到”下拉框完成。中文输入法确认文字时，Enter 不会新建项目。输入框内的撤销保留浏览器原生行为。

Win/Mac 均可导入 JSON、下载 Markdown ZIP，再解压到 Obsidian 仓库。Chrome / Edge 的独立窗口通常可授权目录直接写入；Safari / Firefox 或嵌入页面可使用 ZIP。网页不能自动扫描本机 Obsidian 仓库或打开 Finder / Explorer。

默认数据只存在此浏览器。使用同步面板的配对码连接其他设备，或用 JSON 备份迁移。清除网站数据会删除本机记录。

跨设备同步

复用 PT Universe 的配对码，Todo 数据独立同步，并在浏览器端加密。先在一台设备生成配对码，再在另一台输入。修改先保存在本机，连接后自动同步。

两台设备同时修改时，会保留双方版本并让你选择。配对码可访问数据，请自行保管。
