SkillGraph 回归评测台

在同一组岗位技能题上对比向量检索与关系约束检索，逐题追踪召回、关系和引用错误。

  • 20 道公开合成题
  • 4 个岗位
  • 浏览器本地计算

逐题检查

通过要求答案完整、关系路径匹配、引用可回溯到本次检索。

题集与评测协议

此题集的岗位关系、证据与练习场景均为本项目编写的合成样例。职业术语参考 O*NET Data Scientists。

本地基线使用 TF-IDF 余弦相似度。关系约束基线使用同一排序器，先按给定的岗位实体和关系约束缩小候选范围。两组使用同一结构化证据读取器。关系约束基线测的是给定约束时的检索效果，真实 GraphRAG 的实体识别、生成效果和成本由外部对照结果提供。

召回率为有答案题目的微平均 Recall@K。每题保留首个失败阶段。P50 是本次运行逐题延迟的中位数，导入时可为未知。成本为各题所填 API 费用之和。导入结果仍在本机计算分数。
