下载文件夹收件台

把最近下载的文件归到合适的位置。先确认文件和目标位置，再执行整理。

下载 Windows 工具

Windows PowerShell 5.1 · 无需管理员权限 · 文件和操作记录保存在本机

打开收件台

  1. 下载 Download-Inbox.ps1。
  2. 右键文件，选择「使用 PowerShell 运行」。
  3. 首次打开会读取 Windows 的下载文件夹，也可在顶部换目录。

整理文件

  • 按最近修改时间查看，勾选要处理的文件。
  • 「内容查重」比较同大小文件的 SHA-256。
  • 选择自动分类或指定目录。填前缀可批量改名。
  • 执行前核对目标位置。同名文件会自动编号。

撤回上次

考虑好再开始下一批。收件台保留最近一批的撤回记录。原位置被占用或归档文件已变化时，会跳过该文件并显示原因。
