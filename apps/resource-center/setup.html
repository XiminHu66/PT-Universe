PT UNIVERSE / SETUP

一次性授权设置

只读 · 零新增定时任务

需要配置什么

监控范围只有 GitHub、Oracle VPS 和 Cloudflare。页面由 PT Universe GitHub Pages 托管；取数复用现有 pt-universe-api Worker。原工具中心只负责确认你的身份，确认后立即回到 PT Universe。

用途Worker Secret 名称填写内容
GitHub 仓库、Actions 与账单RESOURCE_GITHUB_TOKEN下方创建的细粒度只读 PAT
Cloudflare 使用量RESOURCE_CF_TOKENAccount Analytics Read 只读 API Token
Cloudflare 账户定位RESOURCE_CF_ACCOUNT_ID对应账户的 32 位 Account ID
Oracle VPS CPU / 内存 / 磁盘无需新增复用已有受保护的 VPS 采样连接

密钥直接填到 Cloudflare 的 Secret 中。页面不接收密钥，仓库不保存密钥。

1. 创建 GitHub 只读 Token

  1. 打开 GitHub，点击头像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。
  2. Token name 填 PT-Resource-Monitor；Resource owner 选择 XiminHu66；Expiration 可设 90 天，过期前替换即可。
  3. Repository access 选择 All repositories，使当前及以后新建的自有仓库都在盘点范围；如果选择 Only select repositories，请把所有要监控的仓库加入，包含私有的播放器和运维仓库。
  4. Repository permissions：Actions = Read-only；Metadata = Read-only（通常自动附带）。
  5. Account permissions：Plan = Read-only，用于读取个人账户的官方账单。其余权限保持未授权。
  6. 生成 Token 后，将完整值填写为下方 Worker 的 RESOURCE_GITHUB_TOKEN Secret。Token 只显示一次，保存在你自己安全的位置。

这些权限不提供修改代码、启动工作流、删除产物或调整预算的能力。现有 $0 付费预算继续保持。

官方说明：创建细粒度 Token · 个人账单接口与 Plan 读取权限

2. 创建 Cloudflare 只读 Token

  1. 打开 Cloudflare API Tokens → Create Token → Custom token → Get started。
  2. 名称填 PT-Resource-Analytics。
  3. Permissions 依次选择 Account → Account Analytics → Read。
  4. Account Resources 选择 Include → Specific account，选正在部署 PT Universe Worker 的账户。
  5. Client IP Address Filtering 留空：请求来自 Cloudflare Worker，出口地址不是你电脑的固定 IP。可设置与 GitHub Token 相同的有效期。
  6. 创建后，将 Token 填入 Worker 的 RESOURCE_CF_TOKEN Secret。
  7. 在 Cloudflare 后台选中对应账户，按 Ctrl + K（Mac：⌘ + K），搜索 Copy account ID 并点击结果复制，将完整 32 位值填入 RESOURCE_CF_ACCOUNT_ID。

现有 Analytics 权限用于读取 Workers 请求、KV 操作、D1 行数、Queues 计费操作，以及可用的 KV / D1 存储峰值样本。个别数据集不可读时会在“读取检查”中标出，不影响其他来源。Browser 复用现有 binding 读取会话历史下限，无需新增 Token，也不启动浏览器。

官方说明：Analytics Token 配置

3. 把三个值保存到现有 Worker

  1. Cloudflare Dashboard → Workers & Pages → pt-universe-api → Settings → Variables and Secrets → Add。
  2. Type 选择 Secret，按页面最上方表格依次填写三个名称和值。名称区分大小写。
  3. 保存后点击页面提供的 Deploy / Save and deploy，使 Secret 生效。仅更新现有 Worker，无需新建服务。

这是 Cloudflare Worker 的运行时 Secret 配置。GitHub 仓库中已有的部署 Secrets 继续按原用途使用。

官方说明：通过控制台添加 Worker Secrets

4. 连接与验收

  1. 回到资源与额度页面。首次访问会复用现有工具中心登录，确认身份后返回 ximinhu66.github.io/PT-Universe/apps/resource-center/。以后只在会话过期时续接。
  2. 打开“读取检查”，确认 GitHub 的私有读取、官方账单和 Cloudflare 从“需要授权”变为“正常”或带明确覆盖范围的“部分覆盖”。配置凭据后点击一次“检查更新”即可立即验收。
  3. “项目与占用”中核对私有仓库是否可见、产物和缓存是否有真实采样时间；默认按占用排序。在总览核对 VPS CPU、内存与磁盘。
  4. 日常打开页面自动更新。若指标过期，页面保留原时间并标为过期；失败不会变成 0 或安全绿色。

GitHub API 原价金额包含公共仓库折扣，存储计量也可能使用 GB-hours / GB-month。官方账单明细与免费额度卡片分开显示，只有可比的官方指标才用于额度比例；现有人工核对快照不会因一次 API 请求成功而改成“最新”。

Oracle VPS 的授权与边界

CPU、内存、根盘和服务健康复用既有采样。你只需完成上面的身份连接，不用填写 SSH 私钥、Oracle 密码或新开公网端口。该连接不提供启停容器、删除文件等操作。

Oracle 月度出站流量目前未接通 OCI Usage API。这与 VPS 实时采样是两类数据；网卡瞬时速度不能代替月度计费流量，因此该项继续显示“待核实”，不需要为当前 VPS 采样额外创建 OCI 用户或政策。

遇到这些状态时

  • GitHub 官方账单未授权：核对账户 Plan 读取权限、Token 有效期和 Resource owner。私有产物不可见时核对 Actions 读取权限及仓库选择。
  • Cloudflare 部分指标不可用：核对 Token 的账户范围、Account ID、Analytics Read；不支持的产品指标会保留未知。
  • API 限流：页面会保留上次数据并等待缓存 / 退避时间，无需反复刷新。
  • 身份连接失败：点击“连接资源后台”重试；供应商 Token 与身份会话独立，不需要把 Token 粘贴到页面或聊天中。
  • Token 到期：在供应商处生成同权限的新 Token，替换相同 Worker Secret 并部署，再回页面验收。
