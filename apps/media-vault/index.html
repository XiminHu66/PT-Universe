如何启动引擎

仓库内已提供 Docker Compose 配置。在下载引擎目录中执行：

docker compose up -d --build
docker compose logs engine

首次启动会生成密钥；填入上方即可。默认只监听本机。跨设备使用需在主机设置 HTTPS 访问入口。
