# Media Vault · 万能下载

PT Universe 独立分项目：`apps/media-vault/`。

## 当前功能与验收边界

| 板块 | 已实现 | 2026-09-29 实际验证 |
|---|---|---|
| 音乐 | 七地区/八曲风榜单与试听；Archive 直接列出 FLAC 文件并播放、下载；Ektoplazm 专辑搜索 | Archive 搜索返回 44 个文件，实际下载 877,343,841 字节文件；ffprobe 确认 FLAC、44.1 kHz、24-bit、双声道。另一个 FLAC 音轨在网页播放超过 24 秒。Ektoplazm `Globular` 查询返回 5 张专辑，并验证一个下载地址返回 ZIP 文件头（整张专辑未下载）。主流商业歌曲无损库仍未接通。 |

## 架构

- GitHub Pages：静态界面、播放器、本地书架和 EPUB 打包。
- Cloudflare Worker `/api/media/*`：按请求解析、来源搜索、缓存；限时 KV 凭据仅允许固定媒体来源流式传输。无需常驻主机。
- 下载凭据一小时过期；重新解析取得新链接。不会保存源站凭据到页面。
- 小 FLAC 保存前检查 `fLaC` 文件头；大于 128 MB 的文件先核验 Range 数据，再交给浏览器下载，避免整个文件驻留 JS 内存。
- 小说遇到来源验证、加载失败、排序规则变化或分页异常时停止；失败不写入章节缓存、不生成残缺 EPUB。
- Actions 负责代码检查、构建部署，以及生成供静态网站发布的每日榜单/更新列表。每日更新列表不等于无人值守整本抓取。
- GitHub-hosted Actions 不作为通用按需下载后台或 CDN。参见 [GitHub Actions 条款](https://docs.github.com/en/site-policy/github-terms/github-terms-for-additional-products-and-features#actions)。
- 原私有引擎代码在 `services/media-engine/`；未部署。按需执行通用 yt-dlp/BT 需要另一个允许这类用途的任务平台和输出存储，当前没有假装已连接的云引擎。

## 验证

```sh
node --check apps/media-vault/app.js
node scripts/media-vault/frontend-test.cjs
npm run check --prefix workers/pt-universe-api
npm run test:media --prefix workers/pt-universe-api
python -m unittest discover -s scripts/media-vault -p 'test_*.py'
```

Worker 部署前运行回归测试：段落恢复、安全表达式、截断正文拒绝、媒体域名校验、RSS 解析、单来源失败时保留其他来源。UI mock 测试仅覆盖界面交互，不能作为真实来源可用的证据。

JSZip 按 MIT 使用，许可证位于 `vendor/JSZIP-LICENSE.txt`。正文段落恢复适配自 MIT 项目 bili_novel_packer，许可证位于 Worker `licenses/`。未将下载文件、小说正文或密钥提交到仓库。

## 2026-09-29 续接修复

- 流式传输仅等待响应头时设置超时，响应体不再被 20 秒计时器截断；回归测试使用延迟响应体验证。
- 附件下载通过命名框架交给浏览器，避免异步取票后的弹窗被拦截。大 FLAC 不整体装入 JS 内存。
- 手动刷新跳过前后端旧缓存；iTunes 不可用时尝试 Apple Music（准确标注榜单类型），再保留已成功的静态快照。
- 阅读请求防止旧响应覆盖新章节；禁用 IndexedDB 的浏览器仍可直接阅读；停止 EPUB 打包不会在最后一章完成时误触发下载。
- 小说本机追更曾支持每日检查；2026-10-02 小说工作台改为专注预览和下载，已移除此页面的来源更新和追更界面。
- 现有磁力/种子入口在未连接引擎时交给本机客户端；不宣称实现浏览器 TCP/UDP BT 或免费云离线下载。
- 右上角可检测服务连接，资源请求的超时、来源失败与缓存数据分别显示。

未解决的上游边界仍保留：Bili 样本截断正文、Nyaa 429、主流商业歌曲稳定 FLAC 源，以及无人值守通用云下载引擎。

### 2026-10-02：含图小说下载

- 参考 `Montaro2017/bili_novel_packer` 的懒加载地址规范化、图文段落恢复与 EPUB 包内图片路径处理（沿用 MIT attribution）。
- 文库按图文出现顺序读取；Bili 段落里的图片随整段恢复顺序，分页及纯插图章节均保留。
- 图片接口只允许来源页面列出的图片，校验公网目的地址、重定向、大小和实际格式；携带源站 Referer，提供跨域响应。
- EPUB 嵌入图片、封面与清单；WebP 转为 PNG，图片去重、解码验证、限速重试和本地缓存；缺图时不提示成功。
- 前端章节缓存升级为 v4，服务端元数据缓存升级为 v8，避免继续使用以前丢失插图的响应。
- 回归覆盖：Worker HTML 解析和图片转发、浏览器含图/纯插图/失败导出、EPUB XML、包内引用和图片解码。

### 2026-10-02：小说三栏工作台与并发下载

- 默认进入小说页；白色主题默认启用，可切换深色并记住选择。
- RSS 风格的小说 / 章节 / 阅读三栏布局；手机切换三个面板。书架显示最后阅读章节和下载按钮，搜索支持书名、简繁体及来源链接。
- 每本下载拥有独立状态、目录快照、取消与重试；最多同时处理三本，其余排队。下载期间可继续阅读和切换小说。
- 进度覆盖正文、插图和打包阶段；正文及图片请求共享来源限速，避免多任务叠加请求速率。
- 完成后保留“保存 EPUB”按钮，支持将多个完成文件合并为 ZIP 保存。浏览器自动下载被拦截时可手动保存。
- 下载需保持页面打开。刷新后的任务标记为可恢复，重新生成时复用 IndexedDB 章节和图片缓存，生成的文件本身不跨刷新保留。
- 浏览器回归验证四本任务的并发上限、取消隔离、继续阅读、缺图失败和重试、主题持久化及桌面/手机布局；真实生成并检查 EPUB 和合集文件。

### 2026-10-02：易读字体与章节选择

- 小说页书名 18px、章节 16px、正文默认 22px；说明、操作按钮和进度文字同步放大，提高浅色主题次要文字的对比度。保留用户手动设置的阅读字号。
- 书架、搜索结果、目录和本章 EPUB 入口统一弹出章节选择窗口；整本默认全选，本章入口默认只选当前章。
- 支持逐章勾选、全选、清空和输入范围（如 `1-20`、`1-5, 8, 12-15`）；范围按目录序号填写，应用后可继续勾选。
- 确认后才加入下载队列，关闭窗口不会下载；空选择不可提交，越界或倒序范围显示错误并保留原选择。
- 下载及重试保留所选章节，按原目录顺序生成 EPUB；非连续选集不会下载未选中的章节正文。旧版连续范围任务仍可恢复。
- 回归新增：复选框/范围/取消操作、选择持久化、选集 EPUB 内容和离线插图、字号、桌面及手机弹窗布局。

### 2026-10-02：统一导航和可调字号

- 所有媒体板块共用顶部导航与操作栏，滚动或切换板块时不再变回左侧导航；顺序为小说、音乐、动漫、BT、视频。
- 小说界面默认字号比上一版减小 1px（书名 17px、章节 15px、正文默认 21px）。已有手动设置的正文字号保留。
- 右上角“设置”分别提供小说界面字号（90–120%）和正文字号（14–32px），即时预览、自动保存、一键恢复默认；阅读器 A−/A+ 与设置保持同步。
- 下载引擎设置移入统一设置窗口，其他板块仍可正常访问；顶部导航字号不随小说界面比例变化。
- 浏览器回归覆盖五个板块在桌面/手机上的导航位置、顺序、设置持久化和恢复，以及原章节选择和并发下载流程。

### 2026-10-02：紧凑 EPUB 与排版预览

- EPUB 默认无首行缩进、1.5 倍行距、0.5em 段间距、章节标题居中；显式设置段落间距，清理段首空格和空段，避免来源缩进与阅读器默认间距叠加。
- 下载窗口新增“排版与预览”，提供紧凑、首行缩进、宽松预设，以及缩进、行距、段间距、字号比例、页面留白和对齐方式调整。可载入所选首章预览实际文字；插图仍完整嵌入导出文件。
- 排版偏好自动保存，每个下载任务保留入队时的设置；本地 TXT 导出也使用同一窗口。已有 EPUB 需重新生成，阅读器自身的排版覆盖设置可能影响最终显示。
- 回归比较实际 EPUB 与预览的样式一致性，验证空段与缩进清理、真实段落保留、设置持久化和任务隔离，以及桌面/手机窗口、七份 EPUB 的 XML、图片与离线引用。
