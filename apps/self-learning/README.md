## 教学与资料

资料核对日期2026-10-02。96份参考资料在`sources.json`记录作者、URL、类型、版本、阅读位置与限制。课程讲义由本站独立编写，不转载教材全文，不自动更改核对日期。

- 当前文档与经典基础分别标注：ESP-IDF核对时stable为v6.1，OpenCV固定4.13.0；板型、接口、环境与实验条件必须对应。
- 硬件结合Espressif、ESPHome、Wokwi、Adafruit与OASIS MQTT标准；仿真不证明真实功耗、电气或无线性能。
- 独立产品结合YC基础讲座、当前Mixpanel分析和Stripe沙盒/事件/订阅文档；本站价格为假设，需求证据不编造，真实收费不在沙盒验收范围。
- 音频结合经典DSP章节和当前MDN Web Audio、Biquad、启动策略及Daisy官方教程；数字振幅不等于已校准声压，浏览器检查不代替听感和硬件实测。
- 摄影结合Nikon基础教程、Adobe当前编辑文档、OpenCV和Google HDR研究；明确2016经典论文与2024研究文章的年份，RAW与新增器材均非必需。
- 原课程继续使用有版本的系统、安全、交互、游戏与金融资料；当期公司事实仍须查官方财报。

120章共238033教学字符，301条章内术语，515条分节关键结论。每章都有至少四节讲解、提前展示的案例起点、对应讲解中的三个案例步骤、一道换条件的推导题、实验与解析。统计包括问题、定义、正文、公式解释、案例、练习与答案，不含标题、导航、reference、代码、表格与互动文字；只用于防止内容退化，不能代替教学质量判断。

阅读默认分节推进，保留阅读全文；术语可以点击查看。桌面章内路径与移动折叠目录、键盘焦点、打印展开与恢复沿用既有体验。教学组织参考Microsoft Learn、JavaScript.info、MDN及Diátaxis的真实教程，未复制其内容。

## 互动实验

10处确定性模型：金融单位经济与DCF、游戏抽牌、系统队列、安全对象授权、HCI颜色对比，以及新增的电池预算、计入支持工时的产品贡献、纯音混叠和曝光关系。每处都有预测任务、参数、过程、结果与边界；参数不作为完成状态保存，复制上下文包含当前参数与结果。

混叠试听由主动手势启动，浏览器按实际sampleRate生成原频率或折叠频率；低数字振幅、3秒限时，停止、改参数、换分节、换页面或隐藏页面时释放声音。它不是完整ADC仿真，使用前仍需降低设备音量。

9份嵌入Python实验在隔离临时目录运行，其中4份新增：同电压功耗预算、现金与时间成本、离散混叠及自生成WAV、独立噪声平均与未对齐移动点。程序不产生真实支付，不连接真实设备。

## 记录与迁移

`pt-learning.v1`保存章节完成、练习、笔记、分节、自检、起点预测、换条件回答与最后位置；`pt-learning.theme`保存主题，`pt-learning.mode`保存阅读方式。记录只存当前浏览器，支持JSON导出/导入，无自动云同步。原五门记录继续兼容，新旧课程可一起迁移。

导入先验证整个文件再合并，同章取较新时间戳；未知章节、无效内容或无效分节不改变原记录。用户文字按文本输出，不能作为HTML执行。系统不依赖Win/macOS专有快捷键。

## 全课程跟学改进（2026-10-05）

120章均用`caseStudy`记录明确交付物、起点预测、三步案例对应的讲解位置，以及独立编写的换条件问题与逐步答案。案例在导读中先给出，再按逐章指定的位置融入概念讲解；可以从起点直接跳到步骤，也可在完整对照中返回相应讲解。步骤位置允许同节出现多步，避免把电流、功率等不同推导机械地均摊。

九门课程各有准备方法与三阶段成果路线。保留原515节和1115个学习单元的索引，旧分节记录可继续使用；新增预测和换条件回答为可选记录字段，旧备份无需补字段。复制上下文、导出、导入及打印同时包含新增内容。所有120道换条件题按章节具体情景写出数字或可观察结果及条件边界；它们不自动评分。

移除照片产品课及摄影课中指定的重复开场和跳场景段落，避免同一解释反复出现；音频实时章节补充按实际块长计算预算。资料核对日期仍保留实际历史日期，内容修改日期与资料核对日期分开。浏览器回归增加案例提前展示、每章3步位置、案例跳转/焦点、默认收起答案及新字段兼容性检查。

9份运行示例补齐准备条件、预期输出与单变量修改；系统第1章代码直接复现案例中的工作目录错误及明确路径修复。运行步骤与代码结果保持对应，不要求初学者自行猜测输入文件和输出。
