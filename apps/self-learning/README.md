| 课程 | 章节 |

资料实际核对日期为 2026-10-02。`data/sources.json` 记录作者、URL、类型、版本、阅读路径和适用限制。

- 经典教材和论文用于成熟基础，年份显式保留，不伪称新版。
- MIT 2026 OS 入口的课表仍建设中，2025 完整课表提供可选深入实验。
- 软件细节使用维护中的官方文档或锁定的支持版本：PostgreSQL 18、Godot 4.7 文档及核对到的 4.7.2 维护版。
- 安全实践包括 OWASP Web Top 10 2025、OWASP GenAI 2025、持续更新的 Cheat Sheets 与 PortSwigger Academy。
- 研究包括 Quake (2025)、BigFANN/PVLDB (2026)、Agent attack-surface SoK v2 (2026)、Human–Agent workshop 议程 (2026)、MORTAR。预印本、研究议程与正式论文分别标明。
- 金融增加 Damodaran 2026 行业/估值数据资料；当期个股事实要求回公司官方财报核对。
- 本站讲义是独立编写的教学内容，不转载原教材全文，不自动更改核对日期。

## 浏览器数据与迁移

`pt-learning.v1` 保存章节完成、练习记录、笔记与最后位置；`pt-learning.theme` 保存主题。页面明确说明只在当前浏览器保存，支持 JSON 导出与导入；没有自动云同步。

导入先验证整个文件，再合并；同章采用更新的时间戳，非法/未知章节不会改变原记录。笔记与回答用文本输出，避免导入内容成为 HTML。页面支持鼠标、触屏、原生键盘操作及明暗主题，避免依赖 Win/macOS 专有快捷键。

## 验证

使用 Node 与 Playwright（已安装浏览器）：

```sh
node scripts/self-learning/check.cjs
```

可用 `CHROMIUM_PATH` 指向已安装 Chromium。测试自建临时 HTTP 服务，检查课程完整性、reference 关系、阅读流程、历史位置、保存、导出/导入、恶意记录拒绝、360/768/1440px 排版与 PT Universe 导航入口。可选 `TEST_BASE` 对已有测试部署检查。

发布沿用根目录 GitHub Pages 工作流。添加课程时更新 manifest 和参考资料；不需要改页面渲染器。
