# 投资工作台

工作台默认打开「标的与决策」。左侧切换持仓或自选，右侧查看操作计划、条件价位、Kronos 情景与历史图。技术、新闻、期权池和个人区间都跟随当前标的。旧 Stock Alert 链接会转到工作台并保留股票代码。

- 止盈区间的下沿是开始评估止盈的参考价。价格低于止损价位时进入止损区间。操作计划从当前或下一次可交易时段起显示 5 个美股交易日的观察期，使用已公布的 NYSE 2026–2028 日历。先看价格是否进入区间，再检查趋势和财报。行情落后于最近一个已收盘交易日时，页面提示刷新并暂停显示操作日期。个人区间可单独设置买入或卖出、填入技术区间后手动调整，保存后用于提醒。
- 「刷新全部」将持仓与自选去重后先核对报价、日线和财报，再由 VPS 单任务串行核对新闻及期权。交易日美西 08:00 自动触发一次，工作台未打开时会在当天首次打开后补刷。页面打开期间检查时间，本地标签页合并重复批次。失败保留最近可用的数据，行情和详细快照沿用既有缓存。标准化季度财报独立缓存六小时。
- 顶栏可打开 CSV 导入窗口。Fidelity 等券商 CSV 在浏览器解析，持仓数量、成本和账户名不随行情请求发送。支持 USD 多头股票及 ETF；现金、期权、空头会在导入预览中跳过。
- Kronos Base 在交易日美西 08:00 与行情刷新同时提交当前标的、持仓和自选。工作台未打开时在当天首次打开后补交。「刷新全部」会提交全批，新加入的标的单独补入现有队列。Kronos 标题旁显示批次完成数与未更新数。模型最多使用 250 根完整日线，至少需 60 根，生成未来十个交易日的四条路径。全天交易的加密货币使用十个自然日。相同标的同一已完成交易日复用成功结果。情景显示四条路径的到期方向、中位收盘价与样本最小至最大收盘价。展开详情可查看操作计划期间模拟收盘落入观察区的路径数与日期。
- VPS 推理一次处理一只标的，限 0.5 核、3 GiB，每个已完成交易日按标的去重，VPS 队列持久化。页面打开时读取当前情景和待完成队列的前几项，已经排队的任务可在关闭页面后继续运行。历史和过期情景标记原行情截止日。
- 「公开交易核验」按议员交易与机构 13F 切换，可按标的、来源和持仓筛选，直接打开官方原文。议员交易显示交易日、披露日与申报金额，13F 显示报告期末与季度持仓变化。交易日美西 08:00 复用当日已更新的 VPS 快照或启动一次抓取，工作台未打开时在当天首次打开后补抓。切换页签只读取快照，抓取失败时保留上次数据。

本地验证使用 `node scripts/investment/test.mjs`，以及 HTTP 静态站端口 8765 上的 `node scripts/investment/holdings-market-test.cjs`。
