# 投资工作台

工作台默认打开「标的与决策」。左侧切换持仓或自选，右侧查看操作计划、条件价位、Kronos 情景与历史图。技术、新闻、期权池和个人区间都跟随当前标的。旧 Stock Alert 链接会转到工作台并保留股票代码。

- 卖出观察区的下沿是复查减仓的参考价。操作计划从当前或下一次可交易时段起显示 5 个美股交易日的观察期，使用已公布的 NYSE 2026–2028 日历。先看价格是否进入区间，再检查趋势和财报。行情落后于最近一个已收盘交易日时，页面提示刷新并暂停显示操作日期。个人区间可单独设置买入或卖出、填入技术区间后手动调整，保存后用于提醒。
- 当前标的按需更新报价、新闻和期权。标准化季度财报独立缓存六小时。打开「持仓管理」或点「刷新证据」时核对列表；公开披露进入核验页后按需更新。
- 顶栏和持仓管理均可打开 CSV 导入窗口。Fidelity 等券商 CSV 在浏览器解析，持仓数量、成本和账户名不随行情请求发送。支持 USD 多头股票及 ETF；现金、期权、空头会在导入预览中跳过。
- Kronos Base 支持 QQQ、NVDA、AMD、GOOGL、SMH。手动生成四条路径，模型使用已完成的 250 个日线交易日，预测未来十个交易日。相同标的同一交易日复用成功结果。情景显示四条路径的到期方向、中位收盘价与样本最小至最大收盘价。展开详情可查看操作计划期间模拟收盘落入观察区的路径数与日期。
- VPS 推理一次处理一只标的，限 0.5 核、3 GiB，固定标的和交易日额度。页面打开只读结果，手动运行在后台完成。历史和过期情景标记原行情截止日。
- 公开披露保留来源归属和交易、披露日期，13F 标为季末持仓。可选 Muse 日报从已有工作台连接读取。

本地验证使用 `node scripts/investment/test.mjs`，以及 HTTP 静态站端口 8765 上的 `node scripts/investment/holdings-market-test.cjs`。
